A SITL run writes a log of everything the stack saw and did. `trace_export`
turns the log into a replay in `reflex-trace/1`, the trace format of
[reflex](https://github.com/branes-ai/reflex), with the field the run flew
as the replay's scene: each obstacle a cylinder drawn as a tree, the goal,
and the geofence. This page plays two replays in reflex's trace player. The
player runs nothing: it shows the logged truth sample by sample, with its
provenance underneath.

Baseline `s0-gt-pid` flies a straight line from the pad to the goal at
3 m/s on the true state, and avoids nothing
([bring-up plan](../plan/bring-up/README.md)). On the
[forest field](../../fields/forest-60.yaml) each seed grows a different
forest, so whether a run gets through is up to the forest: over 100 seeds,
32 reach the goal at every cruise speed tried.

What to look for:

- **The line doesn't bend.** The reference runs straight at the goal, and
  the vehicle follows it into the trunk: the baseline sees the obstacles
  (the oracle reports them every frame) but doesn't use them.
- **The collision event.** Seek to it with its button. Turn on *Collision
  shapes* to see the trunk the vehicle's sphere touched; the canopies are only
  drawn.

## Export a run

Build the tools and record a run, then export it, from the repo root:

```bash
cmake --preset gcc-release && cmake --build --preset gcc-release
b=build/gcc-release
$b/sitl_s0-gt-pid --scenario scenarios/s0-forest.yaml --out run.brlog
$b/apps/trace_export --log run.brlog --scenario scenarios/s0-forest.yaml --out replay.json
```

`--scenario` must be the file the log was recorded from: `trace_export`
checks its hash against the log's, and takes the trace's seed and physics
step and the scorer's collision radius and speed limit from it. `--rate`
sets the sample rate (20 Hz by default). `tools/gen_replay.sh` records this
page's two replays.

To play a replay on a page, import the player and the trace in an `.mdx`
document in `docs/`, as this one does:

```mdx
import TracePlayer from '@branes-ai/trace-player/TracePlayer.astro';
import replay from '@site/traces/my-replay.json';

<TracePlayer trace={replay} title="…?" description="…" plots={[…]} />
```

The player refuses a trace that isn't valid `reflex-trace/1`, so the docs
build fails rather than publish a broken replay.
